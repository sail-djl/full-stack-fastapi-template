# 多环境配置说明

## 概述

项目已实现类似 Spring Boot Profile 的多环境配置机制，通过 `ENV_PROFILE` 环境变量来激活不同的配置环境。

## 配置文件结构

在 `E:\finance\api\` 目录下有以下配置文件：

- `.env` - 基础配置（所有环境共享）
- `.env.local` - 本地开发环境
- `.env.staging` - 测试环境（家庭服务器 192.168.31.150）
- `.env.production` - 生产环境（公网访问，通过 FRP）

## 使用方法

### Windows PowerShell

```powershell
# 本地开发环境
$env:ENV_PROFILE="local"
uv run python app/main.py

# 测试环境
$env:ENV_PROFILE="staging"
uv run python app/main.py

# 生产环境
$env:ENV_PROFILE="production"
uv run python app/main.py
```

### Linux/Mac

```bash
# 本地开发环境
export ENV_PROFILE=local
uv run python app/main.py

# 测试环境
export ENV_PROFILE=staging
uv run python app/main.py

# 生产环境
export ENV_PROFILE=production
uv run python app/main.py
```

### Docker Compose

在 `docker-compose.yml` 中：

```yaml
services:
  backend:
    environment:
      - ENV_PROFILE=${ENV_PROFILE:-local}  # 默认 local
    # ...
```

## 配置优先级

配置加载顺序（后面的会覆盖前面的）：

1. `.env` - 基础配置
2. `.env.{profile}` - Profile 特定配置（会覆盖基础配置）

## 注意事项

1. **安全配置**：非 local 环境必须使用强密码，不能使用 `changethis` 作为 `SECRET_KEY` 或 `FIRST_SUPERUSER_PASSWORD`
2. **生产环境**：部署到生产环境前，请务必修改：
   - `SECRET_KEY`
   - `FIRST_SUPERUSER_PASSWORD`
   - `FRONTEND_HOST`
   - `BACKEND_CORS_ORIGINS`
3. **配置文件**：`.env*` 文件包含敏感信息，不要提交到版本控制系统
