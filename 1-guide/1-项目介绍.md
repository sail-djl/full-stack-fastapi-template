# Full Stack FastAPI Template 项目介绍

## 项目概述

这是一个功能完整的全栈 Web 应用模板项目，基于 FastAPI 和 React 构建。项目提供了开箱即用的用户认证、权限管理、CRUD 操作等核心功能，是快速启动全栈应用开发的理想起点。

## 技术栈

### 后端技术

- **FastAPI** - 现代、快速的 Python Web 框架
  - 自动生成 OpenAPI 文档
  - 基于 Python 类型提示的 API 验证
  - 异步支持，高性能

- **SQLModel** - 基于 SQLAlchemy 和 Pydantic 的 ORM
  - 类型安全的数据模型
  - 数据库操作简化

- **PostgreSQL** - 关系型数据库
  - 生产级数据库支持
  - 通过 SQLModel 进行 ORM 操作

- **Alembic** - 数据库迁移工具
  - 版本化数据库架构管理
  - 自动生成迁移脚本

- **Pydantic** - 数据验证和设置管理
  - 类型验证
  - 配置管理

- **JWT** - JSON Web Token 认证
  - 安全的用户认证机制
  - Token 基础的身份验证

- **Pytest** - 测试框架
  - 单元测试和集成测试
  - 测试覆盖率报告

### 前端技术

- **React 19** - 用户界面库
  - 组件化开发
  - 响应式设计

- **TypeScript** - 类型安全的 JavaScript
  - 编译时类型检查
  - 更好的开发体验

- **Vite** - 现代化构建工具
  - 快速的开发服务器
  - 优化的生产构建

- **TanStack Router** - 类型安全的路由
  - 文件系统路由
  - 类型推断

- **TanStack Query** - 数据获取和状态管理
  - 自动缓存和同步
  - 后台数据更新

- **Chakra UI** - React 组件库
  - 美观的 UI 组件
  - 主题定制支持
  - 暗色模式支持

- **Playwright** - 端到端测试
  - 浏览器自动化测试
  - 可靠的 E2E 测试

### 开发与部署工具

- **Docker Compose** - 容器编排
  - 本地开发环境
  - 生产部署配置

- **Traefik** - 反向代理和负载均衡器
  - 自动 HTTPS 证书
  - 路由管理

- **GitHub Actions** - CI/CD
  - 自动化测试
  - 持续集成和部署

## 核心功能

### 用户管理

- **用户注册** - 新用户可以通过邮箱和密码注册账户
- **用户登录** - JWT Token 认证机制
- **用户信息管理** - 用户可以查看和更新个人信息
- **密码管理** - 支持修改密码和密码重置
- **账户删除** - 用户可以删除自己的账户（超级用户除外）

### 权限管理

- **普通用户** - 只能管理自己的数据和资源
- **超级用户** - 可以管理所有用户和数据
- **基于角色的访问控制** - 细粒度的权限管理

### 数据管理

- **Items（物品）管理** - 完整的 CRUD 操作
  - 创建、读取、更新、删除物品
  - 用户只能管理自己的物品
  - 超级用户可以管理所有物品

### 邮件功能

- **账户创建通知** - 新用户注册时发送欢迎邮件
- **密码重置** - 通过邮件链接重置密码
- **MJML 邮件模板** - 美观的 HTML 邮件模板

### API 文档

- **自动生成 OpenAPI 文档** - 基于代码自动生成
- **Swagger UI** - 交互式 API 文档界面
- **类型安全的前端客户端** - 自动生成 TypeScript 客户端

## 快速开始

### 前置要求

- Docker 和 Docker Compose
- Node.js (使用 nvm 或 fnm 管理版本)
- Python 3.10+ (使用 uv 管理依赖)

### 启动项目

1. **使用 Docker Compose 启动完整环境**：
   ```bash
   docker compose watch
   ```

2. **访问应用**：
   - 前端界面: http://localhost:5173
   - 后端 API: http://localhost:8000
   - API 文档: http://localhost:8000/docs
   - 数据库管理: http://localhost:8080

### 本地开发

**后端开发**：
```bash
cd backend
uv sync
source .venv/bin/activate
fastapi run --reload app/main.py
```

**前端开发**：
```bash
cd frontend
npm install
npm run dev
```

创建新的迁移：
```bash
docker compose exec backend bash
alembic revision --autogenerate -m "描述信息"
alembic upgrade head
```

## 配置说明

项目通过 `.env` 文件进行配置，主要配置项包括：

- `SECRET_KEY` - 应用密钥（必须修改）
- `FIRST_SUPERUSER_PASSWORD` - 初始超级用户密码（必须修改）
- `POSTGRES_PASSWORD` - 数据库密码（必须修改）
- `SMTP_*` - 邮件服务器配置
- `SENTRY_DSN` - 错误追踪配置（可选）
